## 왜 17개인가

지난 시즌 트렌드 시간에 인기 스킬 세트 5종을 깔아봤더니 **신규 스킬 30개**가 들어왔습니다. 거기서 알게 된 것:

- 이름이 흔한 스킬(`design`, `slides`, `brand`)이 계정 전체에 깔리면 **엉뚱한 작업에서 자꾸 튀어나옵니다.** 그래서 이 팩은 전부 `hfk-` 로 시작하고, **이 폴더 안에서만** 돕니다. 다른 폴더에서는 안 뜹니다
- 같은 시간에 본 이야기 셋이 한 말이 같았습니다 — **늘리는 게 아니라 고르는 일입니다**

17개는 **바닥**이지 목표가 아닙니다. 3회차부터 각자 만드는 것이 진짜입니다. 안 쓰는 건 `.claude/skills/` 에서 폴더째 지우세요.

## 안 될 때

| 증상 | 먼저 볼 것 |
|---|---|
| 뭐라고 시켜야 할지 모르겠다 | 신입에게 말하듯 적어보세요. 그래도 막히면 **"내가 뭘 시켜야 할지 같이 정하자"** |
| 결과가 엉뚱하다 | 대개 **범위를 안 정해줘서**입니다. "어디까지 보고 어디부터는 보지 마라" 한 줄 추가 |
| 어제 하던 걸 모르겠다 | `어제 뭐 하고 있었지` — `hfk-recap` 이 복원합니다 |
| 스킬이 안 불려 나온다 | 이 폴더를 열었는지 확인. 그래도 안 되면 이름을 직접 — `hfk-weekly-report 로 주간보고 써줘` |
| 금방 한도에 걸린다 | 끝난 일은 `/clear`, 큰 파일은 `hfk-index`, 긴 결과는 파일로 빼기 |
