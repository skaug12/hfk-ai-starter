# 리캡

## 목적
세션이 끊기면 맥락이 날아간다. **"어제 하던 거 이어서"**를 3초 만에 가능하게 한다.

## 입력
- 기간 (기본: 최근 7일). "지난달 그거"처럼 말하면 그 범위로
- `기록/worklog/` · `결과물/` 의 최근 파일 · `git log` (있으면)

## 순서
1. 기간 안의 `기록/worklog/*.md` 를 최신순으로 읽는다.
2. `결과물/` 에서 그 기간에 만들어지거나 고쳐진 파일을 최신순 10개까지 뽑는다.
3. 아래 **세 줄로만** 복원한다. 길게 쓰지 않는다.
   - **어디까지 했나** — 마지막으로 끝난 것
   - **무엇이 열려 있나** — 하다 만 것, 실패로 남은 것
   - **다음 한 걸음** — 지금 바로 이어서 할 수 있는 행동 하나
4. 근거 파일 경로를 각 줄 끝에 붙인다.
5. "이어서 할까요?"로 끝낸다. **묻고 멈춘다.**

## 결과
- 세 줄 복원 + 근거 경로
- 사용자가 "응" 하면 다음 한 걸음부터 실행

## 하지 않을 것
- **바로 작업을 시작하지 않는다.** 복원하고 물어본다.
- 기록에 없는 걸 추측해서 채우지 않는다. "기록이 없습니다"라고 말한다.
- 요약을 길게 쓰지 않는다. 세 줄을 넘기면 다시 읽게 안 된다.
