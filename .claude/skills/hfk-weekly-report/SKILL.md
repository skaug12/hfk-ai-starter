# 주간 보고

## 목적
한 주에 **실제로 남은 것**을 근거로 보고 초안을 만든다. 기억으로 쓰지 않는다.

## 입력
- 기간 (기본: 지난 월요일~일요일)
- `기록/worklog/` 의 해당 기간 파일들, `결과물/` 의 해당 기간 생성 파일들
- 연결돼 있으면 캘린더·시트 (없어도 된다)

## 순서
1. 기간 안의 `기록/worklog/*.md` 를 전부 읽는다.
2. `결과물/` 에서 그 기간에 만들어진 파일을 목록으로 뽑는다.
3. 세 덩어리로 묶는다 — **끝낸 일 / 진행 중 / 막힌 것**
4. 각 항목에 **근거 파일 경로**를 붙인다. 근거가 없는 항목은 넣지 않고, 끝에 "기록에 안 남은 일이 있으면 알려주세요"라고 묻는다.
5. 막힌 것에는 **무엇이 있어야 풀리는지** 한 줄을 붙인다.
6. `결과물/주간보고-YYYY-WW.md` 로 저장한다.

## 결과
- `결과물/주간보고-YYYY-WW.md` — 끝낸 일 / 진행 중 / 막힌 것, 각 항목에 근거 경로
- 기록에 없어 빠진 것이 있는지 되묻는 질문 한 줄

## 하지 않을 것
- 기록에 없는 일을 **그럴듯하게 지어 쓰지 않는다.**
- 성과를 부풀리는 표현을 쓰지 않는다. 숫자가 있으면 숫자로, 없으면 없다고 쓴다.
- 막힌 것을 빼지 않는다. 그게 보고의 절반이다.
