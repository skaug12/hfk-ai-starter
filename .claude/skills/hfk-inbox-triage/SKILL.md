# 밀린 것 분류

## 목적
쌓인 것 중에서 **내가 손대야 하는 것만** 골라낸다.

## 입력
- 대상 (메일 / 슬랙 / 문자 중 연결돼 있는 것)
- 기간 (기본: 최근 7일)

## 순서
1. 기간 안의 안 읽은 것·답장 안 한 것을 모은다.
2. 네 칸으로 나눈다.
   - **오늘 답해야 함** — 마감이 붙었거나 상대가 기다리는 중
   - **이번 주 안에**
   - **읽기만 하면 됨** — 공지·참조
   - **버려도 됨**
3. "오늘 답해야 함"에만 **답장 초안**을 쓴다. 나머지는 초안을 쓰지 않는다.
4. 초안은 **내 평소 문체**로 쓴다. 참고할 게 없으면 `결과물/` 의 과거 글을 먼저 본다.
5. 목록 + 초안을 `결과물/인박스-YYYY-MM-DD.md` 로 저장한다.
6. 보낼지 말지는 **한 건씩 물어본다.**

## 결과
- `결과물/인박스-YYYY-MM-DD.md` — 네 칸 분류 + 급한 것의 답장 초안
- 승인받은 것만 발송

## 하지 않을 것
- **승인 없이 보내지 않는다.** 예외 없다.
- 읽음 처리·보관·삭제를 **임의로 하지 않는다.**
- 메일 본문을 통째로 대화에 옮겨 붙이지 않는다. 필요한 줄만 인용한다.
- 고객 개인정보가 든 본문을 `결과물/` 에 그대로 저장하지 않는다. 이름은 이니셜로 줄인다.
