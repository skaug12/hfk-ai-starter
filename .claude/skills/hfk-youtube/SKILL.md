# 유튜브 저장

## 목적
**저장만 해두고 다시 안 보는 영상**을 검색 가능한 노트로 바꾼다.

## 입력
- 유튜브 URL 하나 이상
- 무엇을 뽑고 싶은지 (기본: 요약 + 핵심 포인트 + 내 일과의 접점)

## 준비 (처음 한 번)
```bash
# 1) 제미나이 키 — aistudio.google.com 에서 무료로 발급됩니다
#    .env 에 GEMINI_API_KEY= 로 넣습니다 (hfk-secrets 참고)
# 2) 패키지
pip3 install google-genai
```

## 순서
1. URL을 받는다. 여러 개면 하나씩 돌린다.
2. 스크립트를 돌린다.
   ```bash
   python3 .claude/skills/hfk-youtube/scripts/youtube_note.py "<URL>" --out 자료/
   ```
   - **제미나이 키가 있으면** — 영상 자체를 보게 해서 요약한다. 자막이 없어도 된다
   - **없으면** — `yt-dlp` 로 자막을 받아 온다. 자막도 없으면 제목·설명만 받고 그렇다고 알린다
3. 나온 결과를 노트로 다듬는다. **네 칸**으로:
   - **한 줄 요약**
   - **핵심 포인트** 3~5개, 각각 타임스탬프와 함께
   - **내 일과의 접점** — "새로 나왔다"가 아니라 **"내가 이미 하는 일 중 무엇이 한 칸 쉬워지나"**
   - **출처** — URL · 채널 · 길이 · 저장한 날
4. `자료/유튜브/<채널>-<제목>-YYYYMMDD.md` 로 저장한다.
5. 여러 편을 모았으면 `자료/_인덱스-유튜브.md` 를 갱신한다. (`hfk-index`)

## 결과
- `자료/유튜브/*.md` — 네 칸 노트
- 인덱스 한 줄 추가

## 하지 않을 것
- **영상 전체를 받아서 저장하지 않는다.** 노트만 남긴다.
- 자막이 없는데 **본 것처럼 요약하지 않는다.** 키가 없고 자막도 없으면 "요약 불가"라고 남긴다.
- 타임스탬프를 지어내지 않는다. 모르면 비운다.
- 남의 영상 내용을 그대로 옮겨 콘텐츠로 쓰지 않는다. 인용은 출처와 함께.
