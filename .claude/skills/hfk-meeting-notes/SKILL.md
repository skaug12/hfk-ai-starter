# 회의록 정리

## 목적
회의가 끝나고 **누가 무엇을 언제까지 하는지**만 남긴다.

## 입력
- 회의 메모, 녹취록 텍스트, 또는 `자료/` 아래 파일 경로
- 회의 날짜와 제목 (없으면 물어본다)

## 순서
1. 입력을 읽고 아래 네 가지로만 나눈다.
   - **결정된 것** — 확정된 문장만
   - **할 일** — `담당 · 할 일 · 마감일` 세 칸이 다 있어야 한다
   - **결론이 안 난 것** — 논의는 했지만 안 정해진 것
   - **다음 회의** — 날짜·안건
2. 담당이나 마감일이 비어 있으면 **비운 채로 두고 표시한다.** 추측해서 채우지 않는다.
3. `결과물/회의록-YYYY-MM-DD-<제목>.md` 로 저장한다.
4. 맨 위에 **세 줄 요약**을 붙인다.
5. `기록/worklog/` 에 한 줄 남긴다.

## 결과
- `결과물/회의록-YYYY-MM-DD-<제목>.md`
- 담당·마감이 빈 할 일 목록 (있으면 따로 알림)

## 하지 않을 것
- **담당자와 마감일을 추측해서 채우지 않는다.** 비었으면 비었다고 적는다.
- 잡담·여담을 요약에 넣지 않는다.
- 발언자의 말을 **더 매끄럽게 고쳐 쓰지 않는다.** 결정 문장은 원문에 가깝게.
- 외부 공유용 사본을 만들 때는 `hfk-privacy-check` 를 먼저 돌린다.
