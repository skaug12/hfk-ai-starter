# 외부 서비스 연결

## 목적
Claude Code 혼자서는 **내 컴퓨터의 파일만** 다룬다. 연결하면 그 너머까지 직접 다룬다.

## 입력
- 어떤 서비스를 왜 연결하려는지 한 줄

## 순서
1. **먼저 되묻는다** — "이 연결로 무엇을 자동으로 하려고 하시나요?" 용도가 없으면 연결하지 않는다.
2. 그 용도가 **이미 세 번 이상 반복된 일**인지 확인한다. 아니면 이번엔 손으로 하고 나중에 연결한다.
3. 회사 계정이면 **관리자 승인이 필요한지** 먼저 확인한다.
4. 연결에 필요한 토큰은 `hfk-secrets` 절차로 `.env` 에 둔다.
5. `claude mcp add` 로 연결하고, **읽기만 되는 최소 권한**부터 붙인다.
6. 연결 직후 **읽기 한 건**으로 확인한다. 쓰기는 그다음이다.
7. 무엇을 연결했고 어떤 권한인지 `docs/연결현황.md` 에 적는다.

## 자주 쓰는 것
| 서비스 | 되는 일 |
|---|---|
| Google 캘린더 | 일정 검색·확인, 생성·수정 |
| Google Sheets | 명단·출결 읽기·쓰기 |
| Slack | 메시지 발송, 채널 생성, 예약 발송 |
| Apple 미리알림 | 할 일 추가, 마감일 설정 |

## 결과
- 연결된 MCP 서버 하나 + `docs/연결현황.md` 한 줄

## 하지 않을 것
- **쓰기 권한을 처음부터 주지 않는다.** 읽기로 한 번 확인한 뒤에 연다.
- 회사 계정을 **관리자 확인 없이** 붙이지 않는다.
- 용도가 정해지지 않은 서비스를 "일단" 연결하지 않는다.
- 토큰을 대화에 붙여넣게 하지 않는다.
