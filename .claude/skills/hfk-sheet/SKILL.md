# 표 정리

## 목적
매달·매주 손으로 하던 표 작업을 넘긴다. **연결 없이, 내 컴퓨터의 파일로 바로 된다.**

## 입력
- `자료/` 아래 `.xlsx` `.csv` 파일 하나 이상
- 무엇을 알고 싶은지 한 줄

## 순서
1. **먼저 구조만 본다.** 시트 이름, 컬럼 이름, 행 수, 각 컬럼 상위 5개 값. 전체를 통째로 읽지 않는다.
2. 구조를 보여주고 **해석을 확인받는다.** "A열이 날짜, C열이 금액 맞나요?" 여기서 틀리면 뒤가 다 틀린다.
3. 작업한다. 자주 쓰는 것:
   - **집계** — 기간별·항목별 합계·건수
   - **대조** — 두 파일에서 한쪽에만 있는 것 (명단 vs 결제, 발주 vs 입고)
   - **정리** — 중복 · 빈칸 · 형식이 깨진 날짜·숫자
   - **이상치** — 다른 행과 자릿수가 다르거나 범위를 벗어난 값
4. 결과를 `결과물/<원래이름>-<작업>-YYYYMMDD.xlsx` 로 **새로 만든다.**
5. **숫자를 검산한다.** 합계가 원본 총합과 맞는지, 행 수가 맞는지 확인해 한 줄로 보고한다.
6. `기록/worklog/` 에 한 줄.

## 결과
- `결과물/*.xlsx` 사본 한 장
- 검산 한 줄 — "원본 1,204행 → 처리 1,204행, 합계 일치"

## 하지 않을 것
- **원본을 덮어쓰지 않는다.** 항상 새 파일.
- 컬럼 뜻을 **추측한 채로 진행하지 않는다.** 2단계에서 확인받는다.
- 검산 없이 결과를 내놓지 않는다. 표 작업은 틀려도 티가 안 난다.
- 고객 이름·연락처가 든 열을 `결과물/` 에 그대로 남겨야 한다면 먼저 알린다. (`hfk-privacy-check`)
