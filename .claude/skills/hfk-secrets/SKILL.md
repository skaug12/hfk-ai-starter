# 비밀번호 보관

## 목적
토큰·비밀번호를 **대화창에 한 번도 띄우지 않고** 쓰게 한다.

## 입력
- 어떤 서비스의 무슨 값이 필요한지 (값 자체는 받지 않는다)

## 순서
1. `.env` 가 없으면 `.env.example` 을 복사해 만든다.
2. 필요한 항목의 **이름만** 추가한다. 값 자리는 비워 둔다.
   ```
   SLACK_BOT_TOKEN=
   GOOGLE_SHEETS_ID=
   ```
3. `.gitignore` 에 `.env` 가 있는지 확인한다. 없으면 **먼저 넣는다.**
4. 사용자에게 안내한다 — **"`.env` 를 직접 열어서 값을 넣어주세요. 저한테 붙여넣지 마세요."**
5. 이후 작업에서는 항상 **"`.env` 에서 읽어서 써"** 방식으로 한다.

## 결과
- 값이 비어 있는 `.env` 한 장, `.gitignore` 에 등록된 상태
- 사용자가 직접 채워 넣을 항목 목록

## 하지 않을 것
- **값을 대화로 받지 않는다.** 사용자가 붙여넣으면 "그 값은 제가 보면 안 됩니다, `.env` 에 직접 넣어주세요"라고 하고 쓰지 않는다.
- `.env` 의 값을 **화면에 출력하지 않는다.** 항목 이름까지만 보여준다.
- `.env` 를 커밋하지 않는다.
