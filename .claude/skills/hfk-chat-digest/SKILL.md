# 대화 정리

## 목적
밀린 단톡방·채널에서 **내가 해야 할 것만** 건져낸다.

## 입력
- 붙여넣은 대화 원문 (카톡 · 슬랙 · 팀즈 · 문자 무엇이든)
- 내 이름 또는 호칭 (누가 "나"인지 알아야 한다)

## 순서
1. **먼저 개인정보를 줄인다.** 전화번호·주소·계좌번호가 있으면 가린 뒤 진행하고, 가렸다고 알린다.
2. 사람 이름은 **이니셜이나 역할로 바꾼다.** (김민수 → K팀장)
3. 네 칸으로 나눈다.
   - **결정된 것**
   - **내가 할 일** — 마감이 나왔으면 같이
   - **남이 할 일** — 내가 기다리는 것
   - **답장해야 할 것** — 나에게 물었는데 내가 아직 안 답한 것
4. 결정이 안 난 쟁점은 **따로 적는다.** 대화에서 제일 잘 흘려버리는 부분이다.
5. `결과물/대화정리-YYYY-MM-DD-<방이름>.md` 로 저장한다.
6. "답장해야 할 것"이 있으면 초안을 쓸지 물어본다.

## 결과
- `결과물/대화정리-*.md` — 네 칸 + 미결 쟁점
- (요청 시) 답장 초안

## 하지 않을 것
- **실명·연락처를 그대로 파일에 남기지 않는다.** 이니셜로 줄인다.
- 농담·잡담을 요약에 넣지 않는다.
- 누가 무슨 말을 했는지 **바꾸거나 매끄럽게 다듬지 않는다.** 결정 문장은 원문대로.
- 카톡 앱이나 DB에 직접 접근하지 않는다. 이 스킬은 **붙여넣은 텍스트만** 다룬다.
