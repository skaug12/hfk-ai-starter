# 내보내기 전 점검

## 목적
내 컴퓨터 밖으로 나가기 **직전에** 한 번 막는다.

## 입력
- 내보낼 파일 경로, 또는 보낼 메시지 본문

## 순서
1. 대상에서 아래를 찾는다.
   - **이름 + 전화번호 / 주소 / 이메일**이 같은 줄에 붙어 있는 조합
   - 주민번호 · 카드번호 · 계좌번호 형태의 숫자열
   - `token` `secret` `password` `key=` 가 붙은 값
   - 미공개 재무·인사 정보로 보이는 표현
2. 찾은 것을 **위치(줄 번호)와 함께** 목록으로 보여준다. 값 자체는 앞 2~3자만 보여주고 나머지는 가린다.
3. 각각에 대해 **어떻게 할지 물어본다** — 지울지, 가릴지, 그대로 둘지.
4. 정리된 사본을 `결과물/` 아래 `<원래이름>-공유용.<확장자>` 로 만든다. **원본은 건드리지 않는다.**
5. 판정을 한 줄로 알린다 — "보내도 됩니다" / "3곳 정리하고 보내세요".

## 결과
- 발견 목록 (위치 + 가려진 값)
- `결과물/*-공유용.*` 사본 한 장

## 하지 않을 것
- 발견한 값을 **그대로 출력하지 않는다.** 가려서 보여준다.
- 사용자 확인 없이 원본을 고치지 않는다.
- "아무것도 안 나왔다"를 **안전하다는 보증으로 말하지 않는다.** 못 찾는 형태도 있다고 덧붙인다.
