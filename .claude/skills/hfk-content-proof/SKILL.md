# 발행 전 검수

## 목적
나가고 나서 발견하는 일을 **나가기 전에** 발견한다.

## 입력
- 점검할 파일 경로 또는 본문
- `docs/표기규칙.md` 가 있으면 그것을 기준으로 삼는다 (없으면 4단계에서 같이 만든다)

## 순서
1. 본문을 읽고 아래를 찾는다.
   - **표기 흔들림** — 같은 대상을 다르게 적은 곳 (회사명·상품명·직함·날짜 형식)
   - **숫자** — 날짜·요일·금액·인원이 본문 안에서 서로 안 맞는 곳
   - **링크** — 형식이 깨졌거나 비어 있는 곳
   - **문체** — 한 글 안에서 높임말이 섞인 곳
   - **금지어** — `docs/표기규칙.md` 에 적힌 것
2. 표로 보여준다. 컬럼: 줄 번호 · 현재 · 제안 · 이유
3. **한꺼번에 고치지 않는다.** 어느 것을 반영할지 고르게 한다.
4. 새로 합의된 규칙이 나오면 `docs/표기규칙.md` 에 한 줄 추가한다.
5. 고친 결과는 `결과물/<원래이름>-검수본.<확장자>` 로 저장한다. 원본은 두고 간다.

## 결과
- 검수 표 한 장
- `결과물/*-검수본.*` (반영한 경우)
- 갱신된 `docs/표기규칙.md`

## 하지 않을 것
- 확인 없이 **원본을 덮어쓰지 않는다.**
- 글의 **논지나 구성을 바꾸지 않는다.** 표기·사실 정합성까지가 범위다.
- 취향 문제를 오류처럼 적지 않는다. 제안으로 표시한다.
