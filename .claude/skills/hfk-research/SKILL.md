# 자료조사

## 목적
AI에 제일 많이 시키고 **제일 많이 데이는 일**이다. 출처를 강제해서 지어내기를 막는다.

## 입력
- 알고 싶은 것 한 줄
- 쓸 곳 (보고서 / 기획서 / 그냥 파악) — 깊이가 달라진다

## 순서
1. 질문을 **답할 수 있는 형태로 쪼갠다.** "시장이 얼마나 커?" → "국내 / 2024~2026 / 매출 기준 / 어느 기관 집계"
2. 찾는다. 같은 사실은 **출처 2개 이상**으로 맞춰 본다.
3. 각 문장에 **출처와 날짜**를 붙인다. 형식: `내용 (기관/매체, 2026-03)`
4. 세 칸으로 나눠 보고한다.
   - **확인된 것** — 출처 2개 이상
   - **한 곳에서만 나온 것** — 출처 1개. 표시해 둔다
   - **못 찾은 것** — 빈칸으로 남긴다
5. 숫자가 서로 다르면 **평균 내지 않는다.** 둘 다 적고 어디서 갈리는지 쓴다.
6. `결과물/조사-<주제>-YYYYMMDD.md` 로 저장한다.

## 결과
- `결과물/조사-*.md` — 세 칸 + 모든 문장에 출처
- 못 찾은 항목 목록

## 하지 않을 것
- **출처 없는 문장을 쓰지 않는다.** 하나도 예외 없다. 모르면 "못 찾음"이다.
- 기억으로 숫자를 쓰지 않는다. 연도·금액·점유율은 특히.
- 출처가 서로 다를 때 **하나로 합치지 않는다.**
- 블로그·커뮤니티 글을 1차 출처로 쓰지 않는다. 원 자료를 찾아 들어간다.
