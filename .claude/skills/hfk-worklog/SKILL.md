# 작업 로그

## 목적
**"끝나면 한 줄 남기게."** 이게 있어야 나중에 무엇이 언제부터 안 되기 시작했는지 알 수 있다.

## 입력
- 방금 한 작업 (대화 맥락에서 그대로 가져온다)

## 순서
1. `기록/worklog/YYYY-MM-DD.md` 를 연다. 없으면 만든다.
2. 아래 형식으로 **한 줄만** 덧붙인다.
   ```
   - HH:MM · <스킬 이름 또는 작업 이름> · <대상 몇 건> · <성공/실패> · <남긴 파일 경로>
   ```
   예: `- 14:20 · absence-sms-draft · 3건 · 성공 · 결과물/결석문자-0929.md`
3. 실패했으면 **왜 실패했는지 한 줄**을 그 아래 들여쓰기로 붙인다.

## 결과
- `기록/worklog/YYYY-MM-DD.md` 에 한 줄 (+ 실패 시 이유 한 줄)

## 하지 않을 것
- **길게 쓰지 않는다.** 한 줄이다. 길면 안 쓰게 되고, 안 쓰면 없는 것과 같다.
- 고객 이름·전화번호 같은 **개인정보를 로그에 적지 않는다.** "3건"처럼 숫자로만 남긴다.
- 실패한 작업을 빼놓지 않는다. 실패 기록이 더 쓸모 있다.
