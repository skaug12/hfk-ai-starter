# 네이버 블로그

## 목적
글을 쓰고 **스마트에디터에 그대로 붙여넣을 수 있는 상태**까지 만든다. 발행 버튼은 사람이 누른다.

## 입력
- 주제 또는 이미 있는 원고
- 있으면 — `docs/내문체.md`, `자료/` 의 이미지

## 순서
1. 원고가 없으면 먼저 쓴다. `docs/내문체.md` 가 있으면 그 기준으로. (`hfk-my-voice`)
2. 네이버 블로그에 맞게 손본다.
   - 제목 — 32자 안쪽, 검색어를 앞쪽에
   - 첫 문단 — 요약 대신 **구체적인 장면 한 줄**로 시작
   - 소제목으로 3~5덩어리, 한 덩어리는 화면 한 장
   - 이미지가 들어갈 자리에 `[이미지: 무엇]` 표시
   - 마지막에 태그 5~10개
3. 스마트에디터가 깨뜨리는 것을 미리 고친다.
   - 표는 가능하면 목록으로 (에디터에서 자주 깨진다)
   - 코드블록·각주는 지원이 약하니 인용으로
   - **영상 임베드는 붙여넣기 후 반드시 눈으로 확인한다.** 글자로 바뀌어 들어간 적이 있다
4. `결과물/블로그-<주제>-YYYYMMDD.md` 로 저장한다.
5. **붙여넣을 순서를 안내한다.** 에디터 열기 → 본문 붙이기 → 이미지 넣기 → **임시저장** → 미리보기로 확인 → 발행.
6. 발행 후에는 원고와 실제 화면을 **대조**한다. 이게 제일 자주 사고 나는 곳이다.

## 결과
- `결과물/블로그-*.md` — 붙여넣기용 본문 + 이미지 자리 + 태그
- 붙여넣는 순서 안내

## 대량으로 할 때
연재·대량 이관·예약 발행처럼 자동화가 필요해지면 그때 따로 도구를 붙인다. **이 스킬에는 자동 로그인·자동 발행이 없다.** 계정 잠김과 약관 문제가 실제로 발생한다.

## 하지 않을 것
- **자동으로 발행하지 않는다.** 임시저장까지가 이 스킬의 끝이다.
- 네이버 계정 정보를 받지 않는다.
- 남의 글을 옮겨 오지 않는다. 인용은 출처와 함께 분량을 줄여서.
- 대량 발행·자동 댓글·자동 이웃추가를 하지 않는다.
