## 미리 해두실 것 둘

1. **Claude 유료 가입** — Pro 이상. 계정이 있어야 그날 바로 시작합니다
2. **노트북** — 맥이든 윈도우든 상관없습니다

## 현장에서 함께 하는 것

### 1) VS Code 설치
[code.visualstudio.com](https://code.visualstudio.com) 에서 받아 설치합니다.

### 2) Claude Code 설치
VS Code를 열고 확장(Extensions) 탭에서 **Claude Code** 를 검색해 설치합니다.
설치되면 로그인 안내가 뜹니다. 1번에서 가입한 계정으로 로그인합니다.

### 3) 이 스타터 받기
VS Code 안에서 터미널을 엽니다. (메뉴 · 터미널 · 새 터미널)

```bash
cd ~
git clone https://github.com/skaug12/hfk-ai-starter.git 내작업
cd 내작업
```

`git` 이 없다고 나오면:
- **맥** — 터미널이 알아서 설치를 물어봅니다. 허용하면 됩니다
- **윈도우** — [git-scm.com](https://git-scm.com) 에서 받아 설치한 뒤 VS Code를 다시 엽니다

### 4) 시작
VS Code에서 이 폴더를 열고(메뉴 · 파일 · 폴더 열기 · `내작업`), Claude Code 패널에서 말을 겁니다.

```
CLAUDE.md 열어서 나에 대해 물어보고 채워줘
```

## 확인

아래를 쳐서 스킬 11개가 보이면 제대로 된 겁니다.

```
내 스킬 점검해줘
```

## 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| `git: command not found` | 위 3)의 안내대로 git 설치 |
| 로그인이 안 된다 | 브라우저가 기본 브라우저인지 확인. 사내망이면 관리자 문의 |
| 한글 폴더 이름이 깨져 보인다 | 터미널에서 `git config --global core.quotepath false` |
| 스킬이 안 불려 나온다 | 이 폴더를 열었는지 확인. 다른 폴더에서는 안 돕니다 |
