# 나중에 필요해지는 것들

지금 스킬로 깔지 않은 것들입니다. **필요해지는 시점**이 따로 있어서 그렇습니다.

---

## 외부 서비스 연결 (MCP) — 필요해질 때

Claude Code 혼자서는 **내 컴퓨터의 파일만** 다룹니다. 연결하면 그 너머까지 다룹니다.

| 서비스 | 되는 일 |
|---|---|
| Google 캘린더 | 일정 검색·확인, 생성·수정 |
| Google Sheets | 명단·출결 읽기·쓰기 |
| Slack | 메시지 발송, 채널 생성, 예약 발송 |
| Apple 미리알림 | 할 일 추가, 마감일 설정 |

**연결하는 법** — Claude Code에게 그냥 말하면 됩니다.
```
구글 시트 연결해줘
```

**연결하기 전에 스스로 물어볼 것 넷**

1. 이 연결로 **무엇을 자동으로** 하려는가. 용도가 없으면 연결하지 않습니다
2. 그 일을 **이미 세 번 이상** 했는가. 아니면 이번엔 손으로 하고 나중에 연결합니다
3. 회사 계정이면 **관리자 승인**이 필요한가
4. **읽기 권한만** 먼저 붙였는가. 읽기로 한 번 확인한 뒤에 쓰기를 엽니다

토큰은 `hfk-secrets` 로 `.env` 에 둡니다. 무엇을 어떤 권한으로 붙였는지는 [연결현황.md](연결현황.md) 에 적습니다.

## 내 스킬 점검 — 스킬이 5개쯤 쌓이면 (10월 말)

스킬이 하나일 때는 점검할 게 없습니다. 몇 개 쌓이고 나면 **조용히 죽어 있는 것**이 생깁니다. "어제는 됐는데 오늘 안 된다"가 대개 이겁니다.

그때가 되면 이렇게 물으면 됩니다.

```
.claude/skills 전부 읽고, 각각 (1) 다섯 칸이 다 있나 (2) 가리키는 경로가 지금도 있나
(3) 기록/worklog 에 최근 4주 안에 돈 적이 있나 표로 보여줘. 지우는 건 먼저 물어보고
```

## 카카오톡 직접 읽기 — 이번 팩에 없습니다

복사해 붙여넣는 방식은 `hfk-chat-digest` 로 됩니다. 앱 데이터를 직접 읽는 건 넣지 않았습니다.

- 별도 도구 설치가 필요해서 설치일에 감당이 안 됩니다
- 회사 단톡방은 고객 이름·연락처가 그대로 있습니다. [보안.md](보안.md) 의 기준과 부딪힙니다

정말 필요해지면 12월에 개별로 봅니다.

## 네이버 블로그 자동 발행 — 이번 팩에 없습니다

글을 쓰고 붙여넣을 형태로 만드는 건 `hfk-naver-blog` 로 됩니다. **자동 로그인·자동 발행**은 넣지 않았습니다. 계정 잠김과 약관 문제가 실제로 생깁니다. 연재나 대량 이관이 필요해지면 그때 따로 붙입니다.
