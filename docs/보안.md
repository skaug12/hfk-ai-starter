# AI에게 뭘 말해도 되나

Claude Code는 내 컴퓨터에서 작업하지만, **내가 입력한 내용은 Claude 서버로 전송**됩니다. 그래서 구분이 필요합니다.

## 말해도 되는 것

- "매출 시트에 컬럼이 다섯 개 있어" — 구조만 설명
- "이 엑셀을 월별로 분류해줘" — 작업 요청
- "마케팅 카피 초안 써줘" — 콘텐츠 작성
- "경쟁사 가격 비교해줘" — 공개 정보

## 절대 말하면 안 되는 것

- **고객 개인정보** (이름 + 전화번호 + 주소)
- 회사 사내 시스템 비밀번호
- 미공개 재무제표, 인사 정보
- 주민번호, 카드번호, 계좌번호

## 비밀번호는 이렇게 보관합니다

1. Claude에게 **"비밀번호 보관 파일 만들어줘"** (`hfk-secrets` 스킬이 돕니다)
2. 만들어진 `.env` 를 **직접 열어서** 값을 넣습니다
3. 이후에는 **"그 파일에서 읽어서 써"** 라고 시킵니다

이렇게 하면 대화에 비밀번호가 남지 않습니다. `.env` 는 `.gitignore` 에 들어 있어 커밋되지 않고, `.claude/settings.json` 이 Claude의 읽기도 막아둡니다.

## 내보내기 전에 한 번

파일이나 메시지를 밖으로 보내기 직전에:

```
이거 보내도 되나 봐줘
```

`hfk-privacy-check` 가 개인정보·토큰이 섞였는지 훑고, 가린 사본을 만들어 줍니다.

## 기록에 남기는 것

`기록/worklog/` 에는 **숫자만** 남깁니다. "3건 성공"이지 "홍길동 · 010-…" 이 아닙니다.

## 참고 — 안 쓰는 것

대화를 전량 자동 기록하는 도구(claude-mem 류)는 이 팩에 넣지 않았습니다. `.env` 값이나 멤버 명단까지 로그로 남을 수 있어 업무용으로는 권하지 않습니다.
